Variables in CSS

CSS variables, also known as custom properties, are a powerful feature that allows you to store and reuse values throughout your CSS code. They are defined using the -- prefix and can be accessed using the var() function. They are declared in the :root pseudo-class these are global variables. The same variable can be used in multiple places throughout your CSS. The variable can also be delcared as local varibles in each block individually.i.e You can also override the global variables by declaring new values for them in a specific block. These new values will only apply within that block and will not affect the global variables outside of it
