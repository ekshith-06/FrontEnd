# Frontend Tutorials 🚀

A collection of tutorials, practice projects, and notes for learning **HTML, CSS, and JavaScript** from basics to advanced concepts.

## 📚 Topics Covered

### HTML
- Basic structure of an HTML page
- Headings, paragraphs, and text formatting
- Links and images
- Lists and tables
- Forms and input elements
- Semantic HTML

### CSS
- CSS syntax and selectors
- Colors, backgrounds, and borders
- Box model
- Flexbox
- Grid
- Responsive design
- Animations and transitions

### JavaScript
- Variables and data types
- Operators and conditions
- Loops
- Functions
- Arrays and objects
- DOM manipulation
- Events
- ES6 features
